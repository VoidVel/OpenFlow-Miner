Interactive guide

The friendly front door to the API

Each endpoint explained in plain language, with a live Try it panel that calls the real running API. Everything defaults to the seeded receipt dataset, so there's always something to run against without uploading anything.

This page complements — it doesn't replace — the full OpenAPI reference. For the complete, formal spec (schemas, every field, download), see the Scalar API reference ↗.
GET/api/v1/event-logs/{id}

A quick summary of a stored log: case count, event count, distinct activities, and the number of variants.


    


    

      

        GET/api/v1/event-logs/{id}/dfg
      

      
The directly-follows graph — nodes (activities) and edges (A→B, weighted by frequency). Also available as pasteable Mermaid or Graphviz DOT.

      
      
      

    


    

      

        GET/api/v1/event-logs/{id}/variants
      

      
The distinct end-to-end paths cases actually followed, ranked by frequency. top limits how many you get back.

      
      
      

    


    

      

        GET/api/v1/event-logs/{id}/statistics
      

      
Volumes and timing: case & event counts, average and median case duration (both as seconds and a human string), and the most common start/end activities.

      
      

    


    

      

        GET/api/v1/event-logs/{id}/bottlenecks
      

      
Activities ranked by average time until the next step — where delay concentrates. top limits the list.

      
      
      

    


    

      

        POST/api/v1/event-logs
      

      

        Upload a CSV to mine your own log. Send it as multipart form field file; optional fields
        caseId/activity/timestamp/resource map your columns
        (defaults: case_id, activity, timestamp). Returns the new log's summary — including an id you can then query above.
      

      
      
      

    


    

      

        POST/api/v1/api-keys
      

      

        Generate an API key instantly — no signup, email, or account. Send it as the X-Api-Key
        header for a higher rate limit. It's shown once and can't be retrieved later. Full page:
        Get API Key.
